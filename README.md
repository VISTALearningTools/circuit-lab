# VISTA Circuit Lab

**Public release:** v0.2.0  
**VISTA Learning Tools · Imagine · Build · Share**

Interactive learning tool for series and parallel DC resistive circuits, including:

- Auto-generated Series / Parallel / Both problems
- Standard, Mixed, and Challenge problem types
- User-defined solvable problem builder
- SI-prefix-aware values and unit selectors
- Guided solution steps and contextual HELP
- Circuit Data Matrix
- Ohm's Law by Column
- Circuit Rule Check by Row
- Horizontal / Vertical verification
- Drag/tap placement of givens onto the schematic
- Responsive phone layout

## Publish with GitHub Pages

Upload the contents of this folder to the root of the GitHub repository:

- `index.html`
- `.nojekyll`
- `README.md`
- `COPYRIGHT.txt`
- `VERSION.txt`

Then enable GitHub Pages for the repository using the repository root / main branch.

## Developer calibration

The public page hides schematic calibration controls. To enable the calibration tool, append:

`?calibrate=1`

Example:

`https://YOUR-SITE/PATH/?calibrate=1`

Calibration settings saved in developer mode are stored locally in that browser and are intentionally ignored by normal public mode.
